Relay wiring
Which relay contact your lights are physically wired to — the ESP32 uses this to invert its signal correctly. Applied immediately to this profile's Firebase; the ESP32 needs a reboot to pick it up.

Emergency light auto-off (minutes)
Turn the emergency light off after it has been on this long continuously. Blank or 0 = never auto-off. Re-arms whenever a room turns on again. Reboot the ESP32 to apply.

Show slots within (hours)
The activation page shows only slots starting within this many hours from now. Blank = 4 (default). 0 = show all upcoming slots.
Booking requests

Auto-approve requests
Off = every request waits in the Requests tab for you to confirm. On = a request is checked against current availability and confirmed immediately, with no review step.
End-of-slot warning
A single shared beeper sounds one short beep when any room's active slot is a few minutes from ending, and that room's own LED starts blinking for the rest of the window. Leave both blank to disable — existing setups are unaffected. Applied to this profile's Firebase; the ESP32 needs a reboot to pick up a pin change.
Warning beeper GPIO pin

Beep duration per beep (ms)

Beep count
Number of beeps (150ms gap between them). 1 = single beep. 0 = no beep (LED still blinks). Blank = 1

Normally the ESP32 does this automatically at midnight.
